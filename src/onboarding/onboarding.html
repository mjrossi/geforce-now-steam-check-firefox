GeForce NOW check for Steam

You're all set — here's what it does.

Open any Steam game page or your wishlist and you'll see whether the game streams on NVIDIA GeForce NOW: a green marker when it does, a neutral one when it doesn't. Availability comes from NVIDIA's public catalog, cached locally and refreshed every 12 hours.

Checking…

Optional: you can allow the add-on to read NVIDIA's catalog directly. It isn't needed today — checks work without it — but it keeps them working if NVIDIA ever changes how the catalog may be read.
